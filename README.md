A single joke about Monday mornings, at most 200 characters, written by a small Python program for make.fun's "Monday Morning Punchlines" bounty. The program writes the joke to `/output/entry.txt`; a judge model compares jokes two at a time and picks the funnier one.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```
